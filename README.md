# DLR Driver Console Playground

An interactive Docklands Light Railway front-seat pretend driving console playground built with vanilla HTML/CSS, Web Audio API, real audio samples, and a Star Wars hyperspace warp mode!

## Features

- **Iconic London DLR Cockpit Design**: Recreated faithfully from the front-seat passenger child pretend driver console sticker found on TfL DLR trains.
- **Authentic TfL Audio**:
  - Classic DLR **"Bing-Bong"** dual chime
  - Crisp **"Mind the gap between the train and the platform. Please stand clear of the closing doors."** announcement
  - Deep resonant maritime **Woolwich Ferry fog horn** blast
  - **Bow Church Bells** (St Mary-le-Bow carillon peal)
- **Star Wars Hyperspace Warp Mode**: Hold down the green **High Speed** button to engage hyperdrive—complete with 3D starfield warp streaking, cockpit rumble, sci-fi audio sweep, and warp alerts!
- **Auto-Dancing Knobs & Dials**: Rotary knobs, pie gauges, and meters rhythmically rotate and pulse. Click the keyhole lock switch to toggle dance mode.
- **Dual CRT Oscilloscopes**: Real-time canvas radar waves, signal spectrum meters, and speed telemetry.
- **30-Key Interactive Membrane Keyboard**: Play musical notes and train telemetry tones.
- **TfL Trademark Safe**: Redrawn docklands roundel featuring `DOK` with clean high-contrast vector art.

## Running Locally

```bash
bun server.js
# or
python3 -m http.server 4173
```
Then open `http://localhost:4173` in any browser. Enjoy!
